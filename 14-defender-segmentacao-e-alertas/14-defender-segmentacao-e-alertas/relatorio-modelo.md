# Relatório: grupos de clientes e fila de revisão

Copie este arquivo com o seu nome e preencha as seis partes, uma coluna para os grupos e outra para a fila. Cada linha precisa de um nome, um número, uma data ou uma coluna. Linha sem nada disso volta para você.

Comando que gerou os números: `python3 defender.py ...` (anote as opções que você usou).

| Parte | Grupos de clientes | Fila de revisão |
|---|---|---|
| 1. A pergunta e quem decide | Quem usa, que decisão muda, quando. | |
| 2. O que entrou | Linha, data de corte, colunas com o motivo, escala, o que ficou fora. | |
| 3. O resultado técnico | Os números do método, comparados com uma alternativa feita com as mesmas colunas ou o mesmo orçamento. | |
| 4. Quanto se mantém | Outra partida, outra amostra, outras colunas ou outro normal: quantos mudam e o que isso quer dizer. | |
| 5. Para que serve | Cabe na operação? O que muda no trabalho de quem usa? O custo para quem usa. | |
| 6. Limites e próximos passos | O que o resultado não autoriza, como medir se ajudou, quando revemos e o que faz parar. | |
